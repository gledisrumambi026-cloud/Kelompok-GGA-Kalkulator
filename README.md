# Kelompok-GGA---Kalkulator-

## Deskripsi Proyek
Proyek ini merupakan tugas kolaborasi Python
untuk membuat aplikasi kalkulator sederhana.

## Tujuan
Membuat program kalkulator yang dapat melakukan
operasi matematika dasar.

## Fitur
1. Penjumlahan (+)
2. Pengurangan (-)
3. Perkalian (*)
4. Pembagian (/)

## Bahasa Pemrograman
Python

## Cara Menjalankan Program
1. Pastikan Python sudah terinstal.
2. Buka file Kalkulator.py.
3. Jalankan program menggunakan Python.
4. Pilih operasi matematika yang diinginkan.
